# VIP StudioS

A React, Vite, JavaScript, and Tailwind CSS website for social-media management, video shoots, professional editing, and studio enquiries.

## Run locally

```sh
npm install
npm run dev
```

Create a local `.env` from `.env.example` to configure `VITE_PUBLIC_EMAIL` and `VITE_WHATSAPP_NUMBER`. Contact links stay unavailable until real contact details are configured.

## Launch content checklist

- Replace all concept project names, descriptions, and bundled Unsplash concept images with verified studio work and approved media.
- Confirm platform-specific social deliverables, studio/about copy, service area, and public contact details.
- Configure the email and/or WhatsApp environment values before publishing.
- Do not present concept projects as commissioned work or add unverified testimonials, clients, awards, or performance claims.
- Account-growth language is an intention, not a guarantee of reach, followers, or specific results.
